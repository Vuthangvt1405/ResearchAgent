# Plans

- `docs/plans/` holds plans that are still in progress (draft, awaiting answers, or being built).
- `docs/plans/done/` holds plans whose work has been merged into `main`, together with their scaffold reports.

When a plan's PR is merged, move the plan and its scaffold report into `done/` with `git mv`, then update the links that point to them (other plans, `docs/explained/`, README, and the `Plan:` comments in code and tests).

An epic overview (like `dataset-download-plan.md`) stays here until all its tickets are done.
